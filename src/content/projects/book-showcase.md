### What it does

- Browse a collection of books and click any one to open its detail page.
- Layouts adapt to phones and desktops with responsive CSS.

### How it's built

- React components with state management for dynamic rendering.
- Continuous deployment: Netlify rebuilds the site from GitHub on every push.
